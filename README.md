# PC Controller

Desktop-приложение для управления своим ПК через Telegram-бота.

## Что есть сейчас

- Один `EXE` через `py-auto-build.bat`
- GUI на `PySide6` с треем, автозагрузкой и настройками
- Telegram-бот на `python-telegram-bot`
- Inline-панель `/panel`
- Управление питанием, файлами, процессами, вводом текста, hotkeys и мышью
- `AutoAccept` по шаблонам изображений

## Команды Telegram

### Основное

- `/panel`
- `/help`
- `/myid`
- `/ping`
- `/status`
- `/uptime`
- `/screenshot`

### Питание

- `/lock`
- `/sleep`
- `/hibernate`
- `/shutdown [sec]`
- `/reboot [sec]`
- `/cancelshutdown`

### Файлы

- `/pwd`
- `/ls [path]`
- `/cd <path>`
- `/mkdir <path>`
- `/rm <path>`
- `/rmr <path>`
- `/download <path>`
- `/upload [path]`
- `/cancelupload`

### Процессы

- `/tasklist [filter]`
- `/taskkill <pid>`

### Ввод и мышь

- `/printtext <text>`
- `/combination <keys...>`
- `/leftclick`
- `/rightclick`
- `/leftdoubleclick`
- `/middleclick`
- `/righthold [sec]`
- `/movemouse <x> <y> [sec]`
- `/message <text>`
- `/voice <text>`
- `/say <text>`
- `/autoaccepton [timeout]`
- `/autoacceptoff`

### Прочее

- `/openurl <https://...>`
- `/logtail [n]`

Все команды, кроме `/myid`, доступны только `admin_ids`.

## Быстрый старт

1. Создай окружение:
   - `python -m venv .venv`
2. Установи зависимости:
   - `.venv\Scripts\python -m pip install -r requirements.txt`
3. Запусти приложение:
   - `.venv\Scripts\python main.py`
4. В GUI укажи `bot token` и `admin_ids`
5. Сохрани настройки и запусти бота

## Сборка EXE

Запуск из корня проекта:

- `py-auto-build.bat`

Результат:

- `dist\PCController.exe`
- `output\PCController.exe`

## Автозагрузка

Управляется из GUI:

- включение и выключение автозагрузки
- запуск в трей
- автозапуск бота

Используется ключ `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.

## AutoAccept

В настройках есть путь к папке шаблонов `AutoAccept templates`.

- Положи туда изображения кнопок подтверждения
- Запусти `/autoaccepton`
- Бот будет искать совпадение на экране и кликать по найденному шаблону

## Конфиг и логи

- Конфиг: `%LOCALAPPDATA%\PCController\config.json`
- Логи: `%LOCALAPPDATA%\PCController\logs\app.log`

## Безопасность

- Не публикуй `bot token`
- Добавляй в `admin_ids` только свои аккаунты
- Ненужные категории команд можно отключать в GUI

## Большие файлы через Gofile

При скачивании через список файлов или `/download` файлы до 45 МиБ отправляются
в Telegram как раньше. Более крупные файлы загружаются на Gofile через
https://gofile.io/api; после подтверждения размера и MD5 бот возвращает ссылку,
размер и локальный SHA-256. Хранение временное, по правилам Gofile (обычно 10 дней
без активности). Любой обладатель ссылки может скачать файл. Сервис может
нормализовать имя файла. Загрузка выполняется только по запросу администратора
с прежним разрешением `files`; автоматической выгрузки папок нет.

HTTPS, ограниченные чтения до 1 МиБ и одна одновременная загрузка. При ошибке
незавершённая или неподтверждённая ссылка не публикуется; повтор — вручную.
После обрыва файл может остаться у сервиса до автоматического удаления. Gofile
использует гостевую загрузку; токены гостя не сохраняются и не журналируются.
Токен Telegram не передаётся файлообменнику. Новых зависимостей или изменений
конфигурации нет: HTTPX уже входит в зависимости python-telegram-bot.

Проверка: `.venv\Scripts\python.exe -m unittest discover -s tests -v` — 9 тестов.
Проверены также реальные загрузки: APK 416523888 байт, MD5 сервиса совпал с
локальным файлом; отдельный smoke окончательного helper успешно завершён.
DropMeFiles отклонил большой файл как Spam, Filebin разрывал большую загрузку;
эти экспериментальные варианты не входят в EXE.

Сборка: `.venv\Scripts\python.exe -m PyInstaller --noconfirm PCController.spec`.
Перед заменой EXE сохраните резервную копию. Для отката остановите PCController,
верните копию и запустите с `--minimized`.
Сборка из окружения Codex: spec ограничивает PATH системными каталогами Windows
и Python, чтобы не включить несовместимую `icuuc.dll` из Poppler. При изменении
окружения сборки используйте новый `--workpath`, чтобы повторно выполнить анализ
DLL. После сборки проверен запуск EXE с `--help` (код 0) до замены программы.

Ссылки скачивания привязаны к конкретному списку и пользователю. После перезапуска
или обновления списка прежние ссылки явно предлагают открыть папку заново;
неизвестный индекс больше не завершается молча и не отправляет другой файл.
Абсолютный путь повторно проходит текущую проверку разрешений перед отправкой.
Регрессии обработчиков `/start` и загрузчика: 17 тестов успешно.
